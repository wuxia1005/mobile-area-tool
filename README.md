# 房屋面積小工具

正式網址：https://wuxia1005.github.io/mobile-area-tool/

在 iPhone 用 Safari 開啟，透過「分享 → 加入主畫面」保留入口；不需要個人電腦持續開機。

## 版本 1.7・漏字欄位局部重讀

- 明確的陽台、總面積、層次面積及「權利範圍＋面積」列，即使首次辨識沒有數字，也會進行有上限的局部重讀；兩次有效面積一致才採用，不從其他欄位補猜數字。
- 共有面積重讀須保留原有有效持分；新讀出的持分也須交叉一致，不能只因面積相同就覆蓋持分。保留重讀前原文、來源截圖與人工確認。
- 修正局部持分重讀只取得分數時，整列覆蓋造成既有權利標籤與共有面積遺失的問題；只保留同一原列已明確讀出的資料，不跨列或跨戶補值。面積衝突不覆寫。
- 更新讀取器與重讀模組的載入版本，避免新版介面搭配舊版重讀模組。這不代表每張轉存／壓縮圖片均能完整辨識；車位或其他欄位仍可能需手填，沒有通過實際 iPhone 驗收。

## 版本 1.6・欄位與來源截圖合併

- 主建物、附屬建物與共有部分只保留一組輸入欄和坪數，來源截圖直接顯示於該欄下方；共有／車位持分的截圖也放在各自輸入處。
- 移除重複的謄本候選卡片及欄位下方的長檔名／行號文字。單一已帶入來源不再顯示來源選單；多筆或尚未選定的候選仍可明確選擇，不自動拼湊或確認。
- Excel 僅預覽該候選對應的可見儲存格列，並非原始工作簿版面。PDF／圖片保留原圖列截圖，座標不可靠時回退整頁，不以辨識文字冒充原件。
- 截圖依序產生、相同來源共用快取；換文件時釋放圖片，快速改選不會把舊圖帶到新欄位。歧義提示、重新辨識／帶入與完整來源匯出保留。

## 版本 1.5・核對與結果合併

- 流程改為「選擇檔案 → 核對與結果」，核對欄位與換算結果保留在同一頁；確認並計算後，在欄位下方顯示結果，不切換到另一頁。
- 「回到核對欄位」只移動到上方輸入處；實際修改數值、單位、持分、車位設定或取消確認時，立即隱藏並清空舊結果／摘要，停用匯出、分享與複製，重新確認計算後才開放。
- 保留 A 經典金融版型、大字坪數、來源截圖及本機處理；不更動換算或辨識規則。

## 版本 1.4・經典金融

- 右上版本自 1.4 起編號，後續版本依更新遞增；程式套件版本為 1.4.0。
- 上方「選擇檔案」可返回選檔首頁；辨識中點擊會取消本次處理，舊結果不會延遲跳回。
- 採用使用者選定的 A「經典金融」：青綠頁首、白底直列數值、紅色重點及方形操作按鈕。配色參考中國信託官方網站：https://www.ctbcbank.com/twrbo/zh_tw/index.html 。不使用銀行標誌，不代表銀行官方服務。
- 放大結果頁總坪數與各項數值，保留手機寬度與深色模式；辨識、換算及人工核對規則不變。

## 來源截圖版（原面積加強版 4）

- 移除核對畫面上方的大段說明框；「查看來源截圖」只顯示圖片，不顯示 OCR 文字或來源說明段落。
- 謄本候選可查看對應原圖列的局部截圖，無可靠座標時保留整頁；Excel 以可見儲存格的地址／值產生圖片預覽，並非原工作簿版面。
- 不更動辨識、持分確認與換算規則；完整讀取內容仍可自行勾選匯出，但不在來源查看區展示。

## 面積加強版 3

1. 預設開啟「謄本／面積表加強辨識」，不需額外勾選。原圖保留不變；辨識副本抑制紅色浮水印干擾，針對面積及持分分區放大重讀，每頁最多 12 次局部辨識，不移除黑色遮蔽或讀取隱藏文字。
2. PDF 預設自動檢查最多 12 頁的可見頁首，找出單一建物標示頁。不同建物或無法辨識時返回手動選頁，不任選一頁；一般面積表可直接關閉自動模式，每次手動最多 5 頁。
3. 單一且無衝突的面積與持分候選先帶入，平方公尺即顯示坪數；同值的總面積／層次面積視為佐證，不重複相加。任何持分都不自動確認，缺漏與衝突保留待確認；不能靠猜小數點或補零修正。
4. 共有欄填未分攤的共有總面積，範圍選全棟／全層，確認共有持分；土地與所有權、抵押權的權利範圍不會拿來代用。
5. 車位若登記於同一共有建號，可選「同一筆共有總面積 × 車位持分」，另填並確認車位分子、分母。兩組持分分別直接乘共有總面積，不會連乘或重複扣除。若已知本戶車位面積，維持直接輸入即可。
6. 核對共有是否已含車位，最後確認再計算。修改持分或共有基準會取消確認；摘要及 Excel 記載兩組持分與換算方式。

局部重讀仍可能錯讀數字、分母零的個數或中文標籤；不是全部欄位保證自動辨識。車位持分漏讀時可直接補填，不需自己先算車位平方公尺。不同共有建號、未列車位持分或多筆共有項目，請先釐清並拆開核對，不任意套用這個同一共有總面積模式。

手機日常流程：LINE 收件 → 存至 iPhone 檔案／照片 → 選取文件 → 核對 → 計算 → 複製摘要／匯出 Excel／分享。

這是純前端工具，不是 LINE 自動回覆機器人，不需要官方帳號、金鑰、付費 API 或個人電腦常開。發布成免費靜態網站後，手機直接使用；部署狀態見儲存庫的 Actions 與 Pages，實際 iPhone 操作仍需驗收。

## 已實作

- JPG／PNG／WebP 本機 OCR。
- PDF 自動找單一建物標示頁／手動選頁後 OCR，只取可見畫面，不讀取可能被遮蔽的文字圖層；手動每次最多 5 頁，可分次讀取。
- Excel（xlsx、xls、xlsm、xlsb）選可見工作表，略過隱藏列欄；不執行巨集或重新計算公式，缺少快取值不當成零。
- 保守辨識面積候選並保留頁碼／工作表／儲存格，遇多戶或重複候選不任選數字拼湊。
- 平方公尺與坪可分欄指定，已是坪不再換算；本戶／全棟持分及共有部分車位關係需人工確認。
- 十進位有理數計算，最後才四捨五入到兩位；缺值、零與無法計算分開處理。
- 顯示扣車位公設比、公設坪數、車位坪數、含／不含車位總坪數。
- 預設只匯出結果；勾選後另附來源、原讀取內容及修正紀錄。轉傳完整檔前請留意個資及其他戶資料。
- 使用手機原生分享功能（瀏覽器支援時），不自動傳送 LINE。

## 限制與資料安全

- 單檔上限 10 MB；不支援 HEIC，請先另存 JPEG／PNG。超限不會默默截斷。
- PDF 內嵌圖最多 1,600 萬像素；超過時 PDF.js 可能略過，必須對照來源預覽與原文件，缺內容請先另存較小圖片。
- 拍攝歪斜、低解析、表格、中文辨識可能有誤。只有總面積或缺少車位拆分時，工具不猜公設比例。
- 車位持分面積不等於車格長乘寬；土地不納入建物總坪數；約定專用、增建或未登記面積不自動加總。
- Excel 若用色塊、浮動圖片遮住儲存格，不等於真的刪除或隱藏。這類文件請先改成可見畫面截圖，勿直接匯入。
- 辨識與計算在裝置執行；程式與模型從同一網站下載，沒有分析追蹤或付費雲端 OCR。網站供應商仍可能記錄一般網站存取資訊。
- 不把文件或結果保存於 localStorage／IndexedDB；關頁、重新整理或手機回收記憶體後可能遺失，請先匯出。
- OCR 元件初始化中取消時，瀏覽器可能仍要完成初始化後才能終止；再次處理會等待前次清理，不疊加工作。
- 建議 iOS 17 以上，辨識時保持頁面開啟。不宣稱已通過實際 iPhone 測試，也不宣稱可離線執行。

## 建置與本機驗證

需要 Node.js 22 以上與系統 tar。無 npm 套件安裝步驟。

```text
node tools/prepare-site.mjs
node --test tests/*.test.js
node tools/serve.mjs
```

本機網址只供開發測試，不是手機離開電腦後可用的正式網址。`dist/` 是可發布的完整網站；原始 PDF、Excel、圖片不得放進網站或儲存庫。

背景整合測試使用 Codex 隨附 Playwright、PDF-lib 與 Edge，在 `test-results/` 產生明確標示的測試文件，不是正式業務資料：

```text
node tests/browser-smoke.cjs
node tests/ui-navigation.cjs
```

介面測試使用前一支測試建立的合成文件，涵蓋頂部返回選檔、辨識取消、版本、同頁核對與結果、舊結果清除、大字結果與明暗手機版；可加上部署網址測試正式網站。

## GitHub 發布準備

本專案採公開程式碼、私人文件留在手機的方式。請勿將自己的文件或測試產物放進儲存庫；正式部署結果以 GitHub Actions 與 Pages 的狀態為準。

專案已提供手動觸發的 `.github/workflows/pages.yml`。儲存庫只放原始程式與建置工具；Actions 從固定版本來源下載開源依賴、建立 dist 並發布 Pages。程式碼可以公開，私人文件、金鑰、test-results、依賴快取不可上傳。

此工具定位為個人自用計算器，使用仍須符合免費平台條款，不作交易網站或對外收費 SaaS。依賴版本與來源紀錄見 THIRD-PARTY.md；建置時生成 vendor/SOURCES.json 供查核。
